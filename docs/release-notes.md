## Game Brief 1.1.1

**중요: 서명 키가 변경된 새 설치용 APK입니다.** 기존 v1.0.0·v1.1.0 또는 debug 앱 위에 업데이트 설치할 수 없습니다. 필요한 API 키·개인 일정 등을 먼저 별도로 기록한 뒤 기존 앱을 삭제하고 설치하세요. 앱 삭제 시 로컬 데이터가 지워집니다. 이후 릴리즈는 이번 서명 키를 유지합니다.

- Gemini와 RAWG 키를 각각 저장하고 보안 저장소에서 다시 읽어 저장 여부 확인
- 키 저장 시 네트워크 조회를 기다리지 않으며 저장 성공·연결 실패를 구분해 표시
- Gemini 키 확인/모델 업데이트 및 RAWG 연결 확인 버튼 제공
- 현재 계정에서 지원하지 않는 Gemini 기본 모델 대신 실제 사용 가능한 안정판 Flash 선택
- 키 변경 시 이전 모델 목록·제한 대기 상태 초기화, 따옴표가 포함된 복사 입력 정리
- 모든 화면을 시스템 하단 바 안전 영역 안에 배치
- 알려주신 GitHub Secrets 이름으로 서명하고 사용자가 승인한 새 서명 인증서와 일치 확인

설정에서 각 키 입력란 아래의 저장 버튼을 누른 뒤 연결 확인 버튼을 눌러 주세요. RAWG 일정은 달력 탭에서 조회합니다.

키를 소스나 로그에 포함하지 않습니다. 실제 사용자 키와 실제 Android 단말 동작은 자동 테스트와 별도로 확인이 필요합니다. 기존 정식 APK는 삭제 후 설치해야 합니다.
