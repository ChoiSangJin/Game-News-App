## Game Brief 1.0.0

개인용 Flutter Android 게임 뉴스·일정 앱입니다.

### 다운로드 및 설치
- `game-brief-arm64.apk`를 다운로드해 설치하세요.
- Android 7.0(API 24) 이상, ARM64 단말용 정식 Release APK입니다.
- 기존 debug 테스트 앱을 설치했다면 삭제 후 설치하세요. 서명이 다르며 삭제하면 로컬 캐시·개인 일정·설정이 지워질 수 있습니다.
- 체크섬은 `SHA256SUMS`에서 확인할 수 있습니다.

### 기능
- PC Gamer·GameSpot RSS 뉴스, PC/PS5/Nintendo/Mobile 필터
- 12시간 로컬 캐시, 수동 갱신, 오래된 캐시 유지
- 기기 내 제목 번역과 상세 RSS 요약의 지연 번역
- RAWG 발매일 달력(개인 API 키 필요), 쇼케이스·게임쇼 개인 일정 등록
- 선택 일정의 전날 알림 예약·취소

첫 번역에는 모델 다운로드가 필요합니다. Android 13 이상 알림 권한을 허용해야 하며 절전 정책에 따라 알림이 지연될 수 있습니다.

### 검증
Flutter 분석, 테스트 11개 통과(선택 실행 RSS 테스트 1개 제외), ARM64 Release 빌드 및 APK 서명 검증을 완료했습니다. 실제 RSS 수집·파싱은 GitHub Actions에서 통과했습니다. 실제 단말의 설치·번역 모델 다운로드·알림 수신은 아직 검증하지 않았습니다.
