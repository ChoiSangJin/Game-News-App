## Game Brief 1.1.0

- ML Kit 대신 사용자 Gemini API 키로 게임 전문 번역
- Google AI Studio 키 발급 바로가기와 단계별 안내
- Google 공식 시작 예제의 권장 `gemini-3.8-flash` 기본 사용
- 하루 한 번 지원 모델 자동 확인, 설정에서 모델 목록 갱신·변경
- 전체 조회 제거: 기기 선택 후 해당 뉴스만 조회·번역, 제목 최대 20개 배치 요청
- 기기별 12시간 캐시·모델별 번역 재사용·429 자동 재시도 차단
- 상세 RSS 요약은 A/가 버튼을 눌렀을 때만 Google로 전송

설정 → Google AI Studio에서 키 발급 → 키 붙여넣기 → 저장하세요. 키가 없으면 원문을 표시합니다. 모델별 요금·한도는 Google 정책에 따릅니다.

Android 7.0 이상 ARM64용입니다. 기존 정식 v1.0.0과 동일 키로 서명했습니다. 테스트용 debug APK는 삭제 후 설치해야 하며 삭제 시 로컬 데이터가 지워질 수 있습니다.

실제 사용자 API 키를 통한 번역 품질·사용 권한·과금 및 실제 단말 동작은 별도로 확인해야 합니다.
